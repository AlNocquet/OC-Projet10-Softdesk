# SoftDesk Support (Bug Tracker API)

## 🇬🇧 Overview
SoftDesk Support is a secure, RESTful bug-tracking backend built with **Django + DRF**.  
Authenticated users can manage **projects**, **contributors**, **issues**, and **comments**.  
Security uses **JWT**, access follows **OWASP (AAA)**, privacy complies with **GDPR** (age ≥ 15 + consent flags), and lists are **paginated** by default.

### Features
- JWT authentication (access/refresh).
- Projects restricted to their contributors.
- Author-only update/delete (Project, Issue, Comment).
- Issues: **priority** (LOW/MEDIUM/HIGH), **tag** (BUG/FEATURE/TASK), **status** (TO_DO/IN_PROGRESS/FINISHED), optional **assignee** (must be a project contributor).
- Comments with autogenerated **UUID**.
- Global pagination (PageNumberPagination).

### Tech stack
Python 3.10+, Django 4.2+, Django REST Framework, djangorestframework-simplejwt, django-filter.

### Authentication (JWT)
Obtain tokens:
```
POST http://127.0.0.1:8000/api/auth/token/
body: { "username": "<user>", "password": "<pass>" }
```
Use the access token:
```
Authorization: Bearer <ACCESS_TOKEN>
```

### Minimal API map
```
/api/auth/token/                 POST  -> {access, refresh}
/api/auth/token/refresh/         POST  -> new access

/projects/                       GET, POST
/projects/{id}/                  GET, PATCH, DELETE          # author-only write
/projects/{id}/contributors/     GET, POST
/projects/{id}/contributors/{user_id}/  DELETE

/projects/{pid}/issues/                          GET, POST
/projects/{pid}/issues/{id}/                     GET, PATCH, DELETE    # author-only write
/projects/{pid}/issues/{iid}/comments/           GET, POST
/projects/{pid}/issues/{iid}/comments/{id}/      GET, PATCH, DELETE    # author-only write
```

### GDPR & Security notes
- Age check (≥ 15) at signup; consent flags: `can_be_contacted`, `can_data_be_shared`.
- All endpoints require authentication by default; access to a project is limited to its contributors.
- Consider logging sensitive actions (Accounting).

### Pagination
Global DRF PageNumberPagination, `PAGE_SIZE = 10` (use `?page=2`).

### Project structure (simplified)
```
config/         # settings, urls
core/           # health & test views
apps/           # (to create) projects, issues, comments, users
```

La sécurité utilise **JWT**, l’accès suit **OWASP (AAA)**, la confidentialité respecte le **RGPD** (âge ≥ 15 + consentements), et toutes les listes sont **paginées**.

- Commentaires : **UUID** auto.
- Pagination globale.
